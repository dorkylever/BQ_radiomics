# Full scientific stack for the BQ_radiomics container, baked into the image at
# build time. Every entry resolves to a prebuilt manylinux wheel for CPython 3.9,
# so there is no source compilation. numpy is held < 2 (see pip-constraints.txt)
# because numba and the pyradiomics 3.1.0 wheel are not numpy-2 compatible.
#
# This mirrors setup.py's install_requires; the editable `pip install -e .` at
# container-create time then just links the local package (deps already present).
